# Локальные изображения трасс

1. Получить опубликованные конфигурации DG-Edge, точные URL фото, логотипов и схем; включить используемые в GTSh фото трасс. Скачать только track artwork, дедуплицировать по SHA-256 и посчитать размер. Аватары/профили исключить по структуре источника и allowlist путей.
2. Добавить отдельный manifest/генерируемый индекс и обновление: проверка хешей без сети, добавление новых конфигураций, проверка изменившихся URL без повторной загрузки неизменённых файлов. Пакет фото автомобилей не переписывать.
3. Общий local-first рендер в карточках гонок и подробностях: реальные URL из новой разметки, локальное фото/схема/лого, cached network для будущего неизвестного URL. Не менять определение трассы по телеметрии и рисование реальной траектории. Никаких настроек профиля.
4. Тесты покрытия, fallback, разбора источника и запрета попадания аватаров в пакет; проверка в приложении на Mac и узком iPhone с запрещённым HTTP для изображений. Вернуть обычную online-сборку и оставить её открытой.

Последовательное выполнение. Без коммита и пуша. Документ — конкретное предложение для утверждения spec/plan; до согласования допустим только сбор публичных файлов, прямо запрошенный пользователем.
