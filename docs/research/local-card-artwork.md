# Локальные изображения карточек

Used, Legendary и Brand Central используют один локальный набор: **858 уникальных файлов, 32 395 072 байта (30,89 MiB)**. Из них 770 фото автомобилей — 30 071 424 байта; остальные 88 файлов — логотипы и флаги. Галереи, крупные фотографии шоурума и фоны в набор не входят.

`assets/card_images/manifest.json` хранит URL, путь, SHA-256, размер и HTTP validators. Файлы адресуются хешем содержимого; `card_image_assets.dart` — генерируемый индекс. `CardArtworkService` зарегистрирован в AppScope. Общий `CardArtwork` сначала показывает локальное основное фото, при ошибке — локальную официальную миниатюру. Неизвестные будущие URL загружаются через дисковый кэш. У карточек Brand Central и логотипов брендов также локальные источники. Галереи сохраняют прежнее поведение.

Исправлено формирование `car<ID>.png`: повторный префикс `car` удаляется. Неизвестная страна не создаёт запрос `xx.png`. Used использует публичный HTML `https://gtdb.io/gt7/used-cars/` вместо недействующего TLS-хоста api.playstationdb.com. Сопоставление идёт по явным slug и уникальным точным нормализованным названиям официального каталога; неоднозначные совпадения не угадываются.

В приложение включён датированный снимок инвентаря GT7Info и GTDB. Он публикуется до ожидания сети. Обновление источников независимо; ошибка одного не очищает данные другого. Без сети цены и наличие относятся к дате снимка, указанной в интерфейсе, а не выдаются за актуальные.

## Обновление набора перед выпуском

```sh
# Полная проверка SHA-256 без сети
python3 tools/update_card_images.py --verify-only
# Обновить инвентарь и добавить новые фото, пропуская целые локальные файлы
python3 tools/update_card_images.py --refresh-dealers
# Дополнительно проверить изменения существующих URL по HTTP validators
python3 tools/update_card_images.py --refresh-dealers --check-remote
.fvm/flutter_sdk/bin/dart format lib/models/car_dealer/card_image_assets.dart
```

После расширения официального каталога сначала обновить его через `tools/fetch_gt7_cars.py`: updater добавляет миниатюры новых ID и пересобирает точные именные aliases при `--refresh-dealers`. Новые источники можно передать через `--manifest`. Сертификаты проверяются штатно. Индекс публикуется после успешной загрузки всего набора, файлы заменяются атомарно; идентичное содержимое разных URL хранится один раз, старые неиспользуемые хеш-файлы удаляются. Повторный запуск на текущем наборе передал 0 байт. Это инструмент обновления пакета приложения; фонового скачивания всего каталога на устройстве нет.
